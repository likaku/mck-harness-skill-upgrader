### P1 — 门禁机读化（1-3 小时）

**核心原则**：`passed` 由程序输出，不由 AI 口头判断。

**需要建立的门禁**：

| 门禁位置 | 触发时机 | 脚本名 | 产出文件 | passed 条件 |
|---------|---------|-------|---------|------------|
| [阶段 X 结束] | [具体触发条件] | `gate_check_[x].py` | `gate_[x].json` | [具体条件，如 `errors == 0`] |

**gate_check_[x].py 需要检查的项目**：
```python
# 每一项都要有明确的 pass/fail 判断，不能是模糊评估
checks = [
    check_param_format,      # [参数格式检查]
    check_count_limits,      # [数量约束检查]
    check_required_fields,   # [必填字段检查]
    # ... 根据 skill 实际需要
]
```

**ENGINE_BUG_WHITELIST（如适用）**：
```python
# 只有有明确文字证据的条目才能加入白名单
WHITELIST = {
    "[error_category]",  # 证据：[为什么这是设计行为而非用户代码问题]
}
```

**gate_result.json 结构**：
```json
{
  "passed": true,           // 由程序派生，绝对值
  "verdict": "PASS / FAIL",
  "user_errors": [],        // 必须修复的错误
  "whitelist_items": []     // 白名单豁免项（仅供参考）
}
```

**完成标准**：运行脚本 → 控制台输出 PASS → 生成 JSON 文件 → `passed: true`
